# AmeDE

Первый прототип рисует рабочий стол, верхнюю панель, док и меню приложений
через [ame-gfx](../graphics/README.md). Winit обрабатывает ввод и размер
окна, Softbuffer выводит пиксели в существующей графической сессии.

## Запуск

Из каталога `ameos` в работающей сессии X11 или Wayland с Rust и шрифтом
DejaVu Sans. Для другого шрифта укажите файл TrueType с кириллицей через
`AMEDE_FONT`.

```sh
cargo run --locked --release -p amede -- --theme amaterasu
```

- `1`, `2`, `3` или кнопки панели выбирают Amaterasu, Sakura и OLED.
- `F2` или кнопка «Приложения» открывает меню. `Esc` закрывает его.
- `T` или кнопка терминала запускает `xterm` в X11 и `foot` в Wayland.
  В `AMEDE_TERMINAL` можно передать путь к другому исполняемому файлу.

PNG можно получить без графической сессии и оконных зависимостей.

```sh
cargo run --locked --release -p amede --no-default-features -- \
  --theme sakura --preview sakura.png
```

Выбор темы сохраняется в `$XDG_CONFIG_HOME/amede/theme` (по умолчанию
`~/.config/amede/theme`) и восстанавливается при следующем запуске. Если файл
отсутствует или содержит неизвестное имя, используется Amaterasu. Аргумент
`--theme` явно переопределяет загруженную тему; автозапуск Wayfire его не передаёт.
Включение AmeDE в установочный образ пока остаётся задачей дорожной карты.

На FreeBSD 15.0-RELEASE/amd64 в Xvfb проверены отрисовка окна,
переключение тем мышью и клавиатурой, меню и запуск `xterm`.
Проверка запуска в Wayland остаётся открытой.
