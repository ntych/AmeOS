# План разработки

## 1. Основа проекта — текущая итерация

- [x] Зафиксировать исходную ревизию FreeBSD и целевую архитектуру.
- [x] Выделить слой AmeOS, описать границы компонентов.
- [x] Подготовить профиль консольного образа и скрипт сборки.
- [x] Добавить режим просмотра плана и проверки управления сборкой.
- [x] Добавить компактный профиль, проверку среды и native smoke без root.
- [x] Подтвердить полный процесс в FreeBSD VM (compact-amd64, 10 ноября 2026).
- [x] Загрузить ISO/USB, установить базу и перезагрузиться без сети
  (QEMU: BIOS/UEFI, USB через EHCI; установка BIOS/UFS).

Критерий завершения этапа: сохранённые образ, логи, контрольные суммы и протокол
успешной загрузки/установки для конкретного коммита и хоста.

Критерий выполнен для `compact-amd64`; см. [протокол](validation-2026-11.md).
Ошибки чтения через xHCI в QEMU TCG остаются открытым ограничением проверки.

## 2. Оформление и интеграция системы

- [x] Версия продукта отдельно от версии ядра (`AMEOS_VERSION` в профилях,
  `@AMEOS_VERSION@` в overlay).
- [x] `etc/os-release` и `etc/motd` через overlay с подстановкой токенов.
- [x] Скрипт применения overlay (`apply-overlay.sh`) с режимом `--dry-run`.
- [x] Загрузочные ресурсы (`rc.conf.local`, `loader.conf.local`).
- [x] Проверяемый механизм overlay: `apply-overlay.test.mjs` в CI.
- [x] Пакетная база — официальный FreeBSD pkg; upstream — 16.0-CURRENT.
  Профиль `desktop-amd64` с `WITH_PACKAGES=yes` и конфигурацией репозитория
  в `etc/pkg/AmeOS.conf` (overlay). `build-release.sh` поддерживает оба
  режима: без pkg (консольные профили) и с pkg (desktop).

## 3. Прототип AmeDE

- [x] Программный графический API на Rust и SSE2 для смешивания слоёв на amd64.
- [x] Оконный прототип с панелью, доком, запуском терминала и переключением Amaterasu/Sakura/OLED.
- [x] Wayfire 0.8.1+ (официальный FreeBSD порт) как стандартный Wayland-compositor для AmeDE.
- [x] Конфиг Wayfire с автозапуском AmeDE и XWayland для совместимости.
- [x] Сессия-скрипт `amede-session` и XDG session registration (`amede.desktop`).
- [x] Документация: этапы и решения Wayfire-интеграции (см. [stage3-wayfire.md](stage3-wayfire.md)).
- [ ] Проверить на Xvfb (виртуальный X11 для CI/ВМ) и физ хостах с GPU.
- [ ] Сохранение выбранной темы между запусками.
- [ ] Системные уведомления и блокировка экрана.
- [ ] Автоматическое включение пакетов в desktop-образ (pkg post-install или build integration).

Критерий: образ загружается в VM, пользователь входит в AmeDE, запускает
приложения, переключает темы с сохранением выбора и завершает сеанс.

## 4. Повседневная работа

- Настройка сети и звука, мониторов и масштаба.
- RU/EN/JA, шрифты и японский ввод.
- Питание, сон и возобновление на конкретном оборудовании.
- Первый запуск, установка окружения на диск и документация.
- Подписанные пакеты/образы, обновления и восстановление.

Критерий: опубликована матрица проверенного оборудования и воспроизводимый
протокол установки, обновления и отката. Даты релизов пока не назначены.
